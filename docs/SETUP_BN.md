# ResoShare — চালু করার নির্দেশিকা (বাংলা)

এই প্রজেক্টে তিনটি অংশ আছে:

| অংশ | কী করে | কোথায় |
|---|---|---|
| **সার্ভার (ব্যাকএন্ড)** | সব তথ্য, হিসাব, নিরাপত্তা ও অনুমোদন এখানে হয় | `backend/` |
| **শেয়ারহোল্ডার অ্যাপ** | রেজিস্ট্রেশন, শেয়ার কেনা, প্রোফাইল, চার্ট, সার্টিফিকেট, নোটিশ | `android/` (user ফ্লেভার) |
| **অ্যাডমিন অ্যাপ** | অনুমোদন, রেট সূচি, ডিভিডেন্ড, রিপোর্ট, স্টাফ, অডিট লগ, সেটিংস | `android/` (admin ফ্লেভার) |

প্রতিটি অ্যাপের দুটি সংস্করণ:

- **লাইভ (Live)** — আসল সার্ভারের সাথে কাজ করে। সার্ভার চালু না হওয়া পর্যন্ত লগইন হবে না।
- **ডেমো (Demo)** — ইন্টারনেট ছাড়াই নমুনা তথ্য দিয়ে সব স্ক্রিন চালিয়ে দেখার জন্য। এতে ইন্টারনেট পারমিশনই নেই।

---

## ১. ডেমো অ্যাপ দেখা (এখনই)

1. `ResoShare-User-Demo.apk` ও `ResoShare-Admin-Demo.apk` ফোনে ইনস্টল করুন
   (সেটিংসে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে)।
2. **শেয়ারহোল্ডার ডেমো লগইন:** মোবাইল `01911000124`, পাসওয়ার্ড `Demo@1234`
   — অথবা নতুন রেজিস্ট্রেশন করুন। ডেমোতে নতুন অ্যাকাউন্টের KYC ২০ সেকেন্ড পরে আর নতুন অর্ডার ২৫ সেকেন্ড পরে নিজে থেকে অনুমোদন হয়ে যায়, যাতে পুরো প্রবাহ দেখা যায়।
3. **অ্যাডমিন ডেমো লগইন:** ইমেইল `admin@rapti.net`, পাসওয়ার্ড `Demo@1234`, OTP `123456`।

> ডেমোর সব নাম, সংখ্যা ও টাকা নমুনা। দুটি ডেমো অ্যাপ আলাদা — একটিতে কিছু বদলালে অন্যটিতে দেখা যাবে না। আসল সংস্করণে সব তথ্য সার্ভারে থাকে।

## ২. সার্ভার চালু করা (একবার)

যা লাগবে:

- একটি Linux VPS (যেমন Ubuntu 24.04, ২ GB RAM যথেষ্ট) — DigitalOcean, Vultr, Contabo বা দেশি হোস্টিং।
- একটি সাবডোমেইন, যেমন **`share.rapti.net`**। Cloudflare-এ এর জন্য একটি **A রেকর্ড** VPS-এর IP-তে দিন এবং
  **DNS only (ধূসর মেঘ)** রাখুন, যাতে সার্ভার নিজে HTTPS সার্টিফিকেট নিতে পারে।
- VPS-এ Docker: `curl -fsSL https://get.docker.com | sh`

ধাপগুলো:

```bash
git clone https://github.com/SAbidyut/ResoShare.git
cd ResoShare/backend
cp .env.example .env
node scripts/gen-secrets.mjs      # (Node না থাকলে: docker run --rm -v $PWD:/w -w /w node:22 node scripts/gen-secrets.mjs)
nano .env                         # DOMAIN=share.rapti.net এবং ৪টি গোপন মান বসান
docker compose up -d --build      # সার্ভার চালু হবে, HTTPS নিজে থেকেই হবে
```

প্রথম সুপার অ্যাডমিন তৈরি (একবারের অস্থায়ী পাসওয়ার্ড দেখাবে):

```bash
docker compose exec api node dist/src/cli/create-admin.js --name "আপনার নাম" --email admin@rapti.net --mobile 01XXXXXXXXX
```

তারপর অ্যাডমিন অ্যাপে ঐ ইমেইল ও অস্থায়ী পাসওয়ার্ড দিয়ে লগইন করুন → ফোনের **Google Authenticator / Microsoft Authenticator** দিয়ে QR স্ক্যান করুন → ৬ অঙ্কের কোড দিন → নতুন পাসওয়ার্ড দিন।
এরপর **আরও → সেটিংস**-এ অফিসের ঠিকানা, ব্যাংকের নাম, অ্যাকাউন্টের নাম ও নম্বর বসান, আর **শেয়ার ও রেট**-এ রেট সূচি দিন।

### অবশ্যই ব্যাকআপ রাখুন

- `.env` ফাইলটি (বিশেষ করে `DATA_ENC_KEY` ও `HMAC_KEY`) নিরাপদ জায়গায় কপি রাখুন। এগুলো হারালে এনক্রিপ্ট করা NID/KYC ছবি আর পড়া যাবে না এবং সার্টিফিকেটের QR যাচাই কাজ করবে না।
- প্রতিদিন ডাটাবেস ব্যাকআপ:
  ```bash
  docker compose exec db pg_dump -U resoshare resoshare | gzip > backup-$(date +%F).sql.gz
  ```

## ৩. লাইভ অ্যাপ বানানো (সার্ভারের ঠিকানা অনুযায়ী)

লাইভ APK-তে সার্ভারের ঠিকানা ভেতরে বসানো থাকে (নিরাপত্তার জন্য পরে বদলানো যায় না)।
দেওয়া লাইভ APK দুটি **`https://share.rapti.net/`** ঠিকানার জন্য বানানো। অন্য ঠিকানা ব্যবহার করলে:

1. `android/gradle.properties` ফাইলে `RESO_API_BASE_URL=https://আপনার-ডোমেইন/` লিখুন।
2. `android/keystore.properties` ফাইলে সাইনিং কী-এর তথ্য দিন (নিচে দেখুন)।
3. বিল্ড করুন:
   ```bash
   cd android
   ./gradlew assembleUserLiveRelease assembleAdminLiveRelease
   ```
   APK পাবেন `android/app/build/outputs/apk/` ফোল্ডারে।

### সাইনিং কী (খুব গুরুত্বপূর্ণ)

অ্যাপের আপডেট দিতে হলে **একই সাইনিং কী** দিয়ে বিল্ড করতে হবে। কী ফাইল (`resoshare-release.jks`) ও এর পাসওয়ার্ড আলাদাভাবে দেওয়া হয়েছে —
এগুলো GitHub-এ রাখবেন না, নিরাপদ জায়গায় (যেমন পাসওয়ার্ড ম্যানেজার ও অফলাইন USB) সংরক্ষণ করুন।
অ্যাপের ভেতরে এই কী-এর ফিঙ্গারপ্রিন্ট বসানো আছে, তাই কেউ অ্যাপ পরিবর্তন করে অন্য কী দিয়ে সাইন করলে অ্যাপ চালু হবে না।

`keystore.properties` এর গঠন:

```
RESO_KEYSTORE=/পুরো/পথ/resoshare-release.jks
RESO_KEYSTORE_PASSWORD=...
RESO_KEY_ALIAS=resoshare
RESO_KEY_PASSWORD=...
```

## ৪. নিরাপত্তা ব্যবস্থা (সংক্ষেপে)

**সার্ভার**
- পাসওয়ার্ড argon2id দিয়ে হ্যাশ করা; ৫ বার ভুল দিলে অ্যাকাউন্ট সাময়িক লক; প্রতি IP-র অনুরোধ সীমিত।
- লগইন টোকেন ১৫ মিনিটে শেষ হয়; রিফ্রেশ টোকেন প্রতিবার বদলায়, চুরি করা টোকেন আবার ব্যবহার করলে পুরো সেশন বাতিল।
- অ্যাডমিনদের জন্য ২-ধাপ যাচাই (Authenticator OTP) বাধ্যতামূলক; নিষ্ক্রিয় থাকলে অটো লগআউট।
- রোল অনুযায়ী অনুমতি (সুপার অ্যাডমিন, অ্যাকাউন্টস, KYC অফিসার, সাপোর্ট, নতুন রোল) — প্রতিটি অনুরোধে সার্ভারে যাচাই।
- NID নম্বর ও KYC ছবি AES-256-GCM দিয়ে এনক্রিপ্ট করে রাখা; ছবি শুধু KYC অনুমতিপ্রাপ্ত স্টাফ দেখতে পারেন এবং প্রতিবার দেখা অডিট লগে থাকে।
- অডিট লগ মুছে ফেলা বা বদলানো যায় না (ডাটাবেস স্তরে আটকানো + হ্যাশ চেইন)।
- টাকা পয়সা পর্যন্ত পূর্ণসংখ্যায় হিসাব; একই শেয়ার দুইবার বিক্রি হওয়া আটকানো; রেট বদলালে পুরনো রেটে অর্ডার আটকানো।
- সার্টিফিকেটের QR-এ গোপন স্বাক্ষর; জাল বা পুরনো সার্টিফিকেট যাচাইয়ে ধরা পড়ে।

**অ্যাপ**
- শুধু HTTPS; ফোনে বসানো ভুয়া সার্টিফিকেট দিয়ে ডেটা আড়ি পাতা যায় না।
- টোকেন Android Keystore (হার্ডওয়্যার) কী দিয়ে এনক্রিপ্ট করে রাখা।
- স্ক্রিনশট/স্ক্রিন রেকর্ড বন্ধ; রিসেন্ট অ্যাপে তথ্য দেখা যায় না; অন্য অ্যাপ উপরে ভেসে থাকলে টাচ নেওয়া হয় না।
- পরিবর্তিত (re-signed) অ্যাপ, ডিবাগার সংযুক্ত থাকলে অ্যাপ চলে না; রুট করা ফোনে অ্যাডমিন অ্যাপ চলে না, শেয়ারহোল্ডার অ্যাপ সতর্ক করে।
- নিষ্ক্রিয় থাকলে অটো লগআউট; চাইলে ফিঙ্গারপ্রিন্ট/পিন দিয়ে অ্যাপ লক।
- ব্যাকআপে কোনো তথ্য যায় না; রিলিজ বিল্ডে কোড অস্পষ্ট (obfuscated) ও লগ মুছে ফেলা।

## ৫. যা আপনাকে ঠিক করতে হবে

- নিয়ম ও রেগুলেশনের লেখায় `[ ]` চিহ্নিত ঘরগুলো (সর্বনিম্ন শেয়ার, বিক্রির নিয়ম, যাচাইয়ের সময়) অ্যাডমিন অ্যাপ থেকে পূরণ করুন।
- সেটিংসে অফিসের ঠিকানা ও ব্যাংকের তথ্য দিন।
- সাধারণ মানুষের কাছে শেয়ার বিক্রির আগে কোম্পানির আইনি কাঠামো (RJSC, BSEC) একজন কর্পোরেট আইনজীবী/অডিটরের সাথে যাচাই করে নিন। ডিভিডেন্ড ও করের হিসাব অডিটরের সাথে মিলিয়ে নিন।
